# 正式标准库

这里保存的是跨电脑、跨任务复用的正式内容生产 SOP。旧文件路径保留以兼容已有任务，但其内容已更新为融合版；以本索引列出的文件为准。

## 当前多类型生成标准

| 文件 | 用途 |
| --- | --- |
| `00-交付契约与发布级验收_v1.md` | **所有任务必读。** 定义任务启动字段、研究闸门、`complete_draft` 与 `publish_ready` 的边界、完整交付包和 Final 命名规则。 |
| `10-发布级Article-Review工作流_v1.md` | 仅用于用户明确要求的独立回审或旧文优化；新文章默认在 13 中完成终稿。定义事实、内容、SEO、视觉、DOCX/PDF 渲染与最终 QA 的回审步骤。 |
| `11-可执行发布闸门与文件一致性_v1.md` | `publish_ready` 必读。定义不可绕过的发布顺序、产品冲突确认、SERP/关键词/字数、Markdown→Word 一致性、Alt/超链接、哈希匹配渲染记录与检查器。 |
| `12-旧文回审与终稿交付保障_v1.md` | 已有文章的优化/回审必读。定义默认优化模式、内容资产保留审计、压缩限制、方法与关键词回审、场景化补图、最终 Word 主交付物与页面证据。 |
| `13-新文章生成终稿闭环_v1.md` | 新文章 `publish_ready` 必读。规定新文章不因附件而误路由为回审，并在生成流程内直接完成真实视觉、最终 Word、等价性、渲染和完整交付包。 |
| `08-多类型文章调度与共享标准_v1.md` | 所有文章共用的研究、事实、关键词、产品、视觉、QA 与交接流程，以及类型路由。 |
| `09-多类型内容生成Skills_v1.md` | 共用与按类型调用的 Skills。 |

| `02-内容生成Skills_v4.md` | 共享和类型专属 Skills 的兼容入口。 |
| `03-内容生成工作流与测试_v4.md` | 统一路由、生成、测试与交接流程。 |
| `04-高转化How-to文章内容结构标准_v3.md` | How-to 的兼容结构入口；仅适用于 How-to。 |

## 使用原则

- 本目录是规则来源；项目资料、关键词数据和最终交付物不要混放进来。
- 新增或调整类型时，先更新对应 Type Module、调度标准、Skills 与测试用例，避免只改提示词而不改验收规则。
- 当文件规则出现冲突时，以事实准确性、用户搜索意图和可执行性优先。
