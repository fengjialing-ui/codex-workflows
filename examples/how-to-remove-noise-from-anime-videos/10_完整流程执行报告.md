# 完整流程执行报告

| 节点 | 输入 | 核心产出 | 状态 | 质量门槛 |
|---|---|---|---|---|
| 1. 任务建档 | 主题 | 英文 How-to，教程优先 | 通过 | 页面类型明确 |
| 2. 初步意图 | 关键词 | 诊断、方法、工具、线条保护 | 通过 | 未先定单一工具 |
| 3. SERP 采样 | 当前搜索结果 | 7 类样本 | 通过 | ≥3 个有效竞品 |
| 4. 竞品分析 | 页面正文 | Must Cover/Improve/Differentiate | 通过 | 非标题罗列 |
| 5. 最终意图 | SERP + 用户任务 | 信息型+商业调查 | 通过 | 支持 Methods 决策 |
| 6. 关键词规划 | 主题实体 | 主次词、长尾、章节映射 | 通过 | 自然埋词 |
| 7. 方案研究 | 用户场景 | 候选池筛选后保留 4 个非重复方法 | 通过 | 数量非预设；覆盖不同用户 |
| 8. 产品事实预校验 | 白皮书+官网 | 模型、控制、预览、边界 | 通过 | 无凭记忆功能 |
| 9. Methods 决策 | 方案池 | Source / Manual / VikPea / FFmpeg | 通过 | 数量与顺序有调研依据；产品位置非固定 |
| 10. Brief | 前述产出 | 页面目标、问答、转化、边界 | 通过 | 引用竞品机会 |
| 11. H 标签规划 | Brief | 1 个 H1；Methods 同级 H2 | 通过 | 无跳级 |
| 12. 大纲审核 | 标准 | 保留 Quick Answer、案例、FAQ、Verdict | 通过 | 关键模块无缺失 |
| 13. 分章节写作 | 大纲+知识库 | 完整英文文章 | 通过 | 每个 Method 可执行 |
| 14. 产品 Method 审核 | 官网事实 | 场景、映射、9 步、案例、限制 | 通过 | 无通用硬推 |
| 15. 事实校验 | 文章 | 事实来源表 | 通过 | 无虚构数值/评价 |
| 16. SEO 优化 | 关键词图 | Title、Meta、H、FAQ、alt | 通过 | 不改变方法逻辑 |
| 17. 视觉生产 | 视觉 Brief | 16:9 原创示意图 | 通过 | 明确非产品截图 |
| 18. 标准回审 | 全文+标准 | 逐项证据报告 | 通过 | 阻断项为 0 |
| 19. Word 导出 | 文章+图片 | DOCX | 通过 | 待渲染后最终确认 |

## 回流记录

- 初版方案曾考虑把“AI 工具”作为单独推荐模块；按正式标准回流到 Methods 决策，改为与其他方法并列。
- 竞品偏重单工具三步法；回流 Brief，补入诊断表、源文件法、手动法和 FFmpeg。
- 产品案例无真实测试数据；回流事实校验，改为明确标记的 recommended test scenario。
