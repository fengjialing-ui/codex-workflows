# 正式标准库

这里保存的是跨电脑、跨任务复用的正式内容生产 SOP。文件保留原始版本号；除非明确升级，否则以当前列出的版本为准。

## 必读基础

| 文件 | 用途 |
| --- | --- |
| `01-内容生成标准体系_v3.md` | 质量优先级、硬规则、审查维度与交付阻断条件。 |

| `03-内容生成工作流与测试_v4.md` | 工作流阶段、测试要求、产出物与回流机制。 |

## 使用原则

- 本目录是规则来源；项目资料、关键词数据和最终交付物不要混放进来。
- 新版本先经实际任务验证，再替换当前正式版本；旧版本放入 `archive/` 而不是删除。
- 当文件规则出现冲突时，以事实准确性、用户搜索意图和可执行性优先。
