# 内容生成流程迁移与弃用说明 v2

## 1. 文件定位

本文件不再是可执行标准，只保留迁移背景，避免旧规则与融合版并行。执行时不得将本文件作为规则来源。

## 2. 已解决的问题与现行来源

| 历史问题 | 现行规则来源 |
| --- | --- |
| 多 H1、标题层级混乱 | `01-内容生成标准体系_v3.md`、`03-内容生成工作流与测试_v4.md` |
| How-to 先定 Methods、后补研究 | `07-How-to文章内容生成工作流_v5.md` |

| 关键词硬塞、批量文章同质化 | `01` 的意图驱动覆盖与独立研究护照 |
| 只适用于 How-to | `08`、`09` 和 `types/` 下的五类专属模块 |
| 虚构实测、排名或产品优势 | `01` 的证据边界与类型文件的结论规则 |

## 3. 迁移原则

- 旧任务如引用 `01` 至 `05`，可继续使用原文件路径，但必须按其融合版内容执行。
- 新任务从 `08-多类型文章调度与共享标准_v1.md` 开始路由，再读取相应类型文件。
- 文章生成完成后只交接给独立的文章回审工作流；生成端的 QA 不代替回审。
