# 正式标准库

这里保存的是跨电脑、跨任务复用的正式内容生产 SOP。旧文件路径保留以兼容已有任务，但其内容已更新为融合版；以本索引列出的文件为准。

## 使用原则

- 本目录是规则来源；项目资料、关键词数据和最终交付物不要混放进来。
- 新增或调整类型时，先更新对应 Type Module、调度标准、Skills 与测试用例，避免只改提示词而不改验收规则。
- 当文件规则出现冲突时，以事实准确性、用户搜索意图和可执行性优先。
